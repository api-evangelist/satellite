# Satellite IM

> Satellite IM builds privacy-focused, decentralized peer-to-peer communication
> software. Its core is Warp, a Rust "interface-driven distributed data service"
> that provides end-to-end-encrypted chat, voice, video, and file sharing with
> data stored on IPFS. Uplink is a customizable decentralized chat application
> built on top of Warp. Satellite is a crypto/web3 company backed by Multicoin
> Capital.

## Overview

- Product family: Warp (core Rust data service) and Uplink (decentralized chat client).
- Architecture: peer-to-peer, end-to-end encrypted, IPFS-backed storage.
- Developer surface: no hosted REST/GraphQL API. Integration happens through a
  WebAssembly/TypeScript library and the open-source Rust crates.
- License: MIT (Warp).
